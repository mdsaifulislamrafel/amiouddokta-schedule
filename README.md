# Schedule Management (আমিও উদ্যোক্তা)
1. `npm install`
2. `.env.example` কপি করে `.env.local` বানান, মান বদলান
3. `public/logo.jpg` এ আপনার লোগো দিন (জলছাপও এই ফাইল থেকেই হবে; আলাদা চাইলে `watermark.png` দিয়ে agreement পেজে নাম বদলান)
4. `npm run dev` → http://localhost:3000 → লগইন করুন (ADMIN_USER / ADMIN_PASSWORD)

## টাকা গ্রহণকারী (👤 মেনু)
- CEO / COO / GM ইত্যাদি ব্যক্তিদের নাম, ফোন ও পদবি দিয়ে যোগ করুন (প্রত্যেকে একটি ইউনিক কোড পায়: RC-001)
- টাকা জমা নেওয়ার সময় "কার কাছে জমা দিয়েছে" বাছাই করুন — টাকা সেই ব্যক্তির হাতে (holding) দেখাবে
- গ্রহণকারীর খাতা থেকে রশিদ বাছাই করে অফিসে জমা দিন → অফিস "টাকা বুঝে পেয়েছি" চাপলে স্ট্যাটাস হবে "অফিস বুঝে নিয়েছে"
- প্রতিটি হ্যান্ডওভারের স্লিপ প্রিন্ট (HO-00001), WhatsApp এ হিসাব পাঠানো, হাতে রাখার সীমা পার হলে সতর্কতা
